# МИС проект – Симеон Сотиров, 12 клас

Фирма: TextileCraft Bulgaria OOD
Сектор: текстилна промишленост, производство (OT)

Управлението е в Сливен, фабриките са в Нова Загора и Котел.
PLC машините говорят с MES сървъра, а качественият контрол праща резултати към централата.
Работниците в производствената мрежа нямат интернет.

В лабораторията: LAN1 е Сливен, LAN2 е Нова Загора. Котел ще бъде добавен по-късно.
